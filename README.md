## 🎯 Sobre Este Repositório

Este repositório contém todos os projetos desenvolvidos ao longo das **14 sprints** do bootcamp TripleTen. Cada projeto demonstra aplicação prática de conceitos de análise de dados, desde fundamentos de Python até técnicas avançadas de machine learning e automação.

**Objetivo:** Construir um portfólio sólido que demonstre evolução técnica, capacidade de resolver problemas reais e domínio de ferramentas essenciais para análise de dados.

## 🛠️ Tecnologias por Fase

### Fase 1: Fundamentos
- **Python** — Sintaxe, estruturas de dados, funções
- **Pandas** — Manipulação de DataFrames
- **NumPy** — Computação numérica
- **Matplotlib & Seaborn** — Visualização básica
- **Git & GitHub** — Controle de versão

### Fase 2: Projeto Integrado 1
- Python + Pandas + Estatística
- Análise exploratória de dados (EDA)
- Modelagem preditiva inicial

### Fase 3: SQL e Negócio
- **SQL** — Queries, joins, subqueries
- **PostgreSQL / MySQL** — Bancos relacionais
- **KPIs e Métricas** — Análise de negócio
- **A/B Testing** — Testes estatísticos
- **Data Storytelling** — Comunicação de insights

### Fase 4: Projeto Integrado 2
- SQL avançado
- Business Intelligence
- Dashboards e visualizações

### Fase 5: Automação e ML
- **Automação de Pipelines** — Scripts e agendamento
- **Machine Learning** — Regressão, classificação
- **Previsões** — Séries temporais
- **Scikit-learn** — Biblioteca de ML

### Fase 6: Projeto Final
- Stack completa de dados
- End-to-end solution
- Apresentação profissional
